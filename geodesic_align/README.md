# geodesic_align

这个包把一张已填模板上的列还原成源表规则。分流只看格子里的字符，不看列名里的业务词。能编成复数的列走数字通道。其余自然语言走球面测地线。两条通道的结果最后都收成同一条映射：搬运、并集、派生、正则，或者留给手工输入。

数字列的值不进 BERT，也不进切空间。文本列的句子不编成复数。

## 复数

一格编成

\[
z = x + yi
\]

实部 \(x\) 是可比较的量。虚部 \(y\) 只表示这一格干净不干净，不参与加减乘。

| 虚部 | 含义 |
| --- | --- |
| \(y = 0\) | 干净实数。普通数值、合法日期的 Excel 序列、纯时刻的日分数都在这里。 |
| \(y > 0\) | 日期非法，已经向下钳到合法日。\(y\) 是被钳掉的天数。例如 `2026-02-30` 钳到 2 月 28 日，\(y = 2\)。 |
| \(y = -1\) | 哨兵 \(0 + (-1)i\)。空格、`N/A`、`暂无`、`-` 都落在这里。不使用 NaN，也不抛异常。 |

两枚哨兵不相等。只要有一侧 \(y < 0\)，`z_eq` 就是假。两侧都不是哨兵时，还要实部差的绝对值小于 \(10^{-9}\)，并且虚部严格相等。因此合法日和被钳过的同日不相等，空白和空白也不相等。

入集合之前把实部和虚部各自四舍五入到 8 位，再当作键。不用 Python 原生 `complex` 做集合元素，避免二进制浮点把同一个数收成两份。

日期的实部是从 `1899-12-30` 起算的 Excel 序列。`2026-10-08` 和整数 `46303` 是同一个 \(z\)。时刻折成一天的小数，正午是 \(0.5\)，加在日期实部上。百分号先除以 100。币符和千分位剥掉。会计括号 `(1,234.50)` 记成负数。这些清洗都发生在变成 \(z\) 之前。

结构化代码不进 \(z\)。它没有稳定的实部，搬运时比去掉空白后的原文。

### 复数结果怎样决定下一步

哨兵（\(y < 0\)）不进入主键集合。集合是空的列直接放弃，不参与覆盖度。

对目标离散列集合 \(S_D\) 和源列集合 \(S_S\)：

\[
\mathrm{Coverage} = \frac{|S_D \cap S_S|}{|S_D|}, \quad
\mathrm{Uniqueness} = \frac{|S_S|}{\text{源表非空行数}}, \quad
\mathrm{Score} = \mathrm{Coverage} \times \mathrm{Uniqueness}
\]

覆盖度为 1 且唯一率不低于 0.8 的配对成为行指针。没有单列能盖住时，才用多列并集。空的目标格指针记为 `None`，不因为缺指针否决整列。

有了指针之后，非主键列只在已填行上做 `z_eq`。有效样本全部相等，这一列就是搬运，代数不再试。搬不动，再试二元 `+`、`-`、`*`。公式要求每一行虚部都是 0，并且两个操作数的干净实部标准差都大于 0，从而挡掉加零、乘一和常数列。仍是手工输入的列，沿同一批指针做正则：目标字面必须是源格的连续子串。符号轨先试具名锚点、括号和分隔符；闭环失败再问本地 `gemma-4-e4b-it-coder`，由 Python 对全部样本回测。字面不是子串的日期，仍用捕获组解析后的 \(z\) 比对。正则使用的是指针，不是「两表行数相等」。

## 文本

文本列先离开数值。每一行拼成「列名：值」，空值和哨兵不进句子。整句只做一次 BERT 前向，得到每个内容 token 的隐向量。列名在句中的字符区间决定哪些 token 属于这一列。重叠长度大于 0 的隐向量取平均，再单位化。这一步的结果是球面上的一个点，还不是分类。

单位向量活在球面 \(S^{d-1}\) 上。后面的长度、搬运和能量都在这个球的切空间里做，避免在欧氏空间里把方向和长度混在一起。

`GAUSS_SIGMA` 是列名中心到 token 的高斯宽度。重叠比例达到 `OVERLAP_TAU`（0.85）的 token 才进入加权平均，然后再单位化。谱分解后，小于噪声底或小于最大奇异值乘 `SPECTRUM_OMEGA` 的方向丢掉。这是 ω 截断，不是余弦门槛。

### 从一点到一朵云

分类需要的不是单点，而是这列名字在各行上的散布。先在观测均值的切空间里取主成分，再只沿这些主方向做 Euler–Maruyama。正交于该子空间的方向只加 \(1/\sqrt{D}\) 的背景噪声，避免 768 维各向同性噪声把能量洒进补空间。记切投影为 \(P_x\)，主切向基为 \(B\)，步长 \(\Delta t = 0.05\)，步数 40，阻尼 \(\lambda = 1\)：

\[
\xi = z B + 0.1\, D^{-1/2}\eta, \quad
x \leftarrow \mathrm{unit}\Big(x + P_x\big(-\lambda (x - x_0)\big)\Delta t + \sigma \sqrt{\Delta t}\, P_x(\xi)\Big)
\]

短文本 \(\sigma = 0.08\)，长文本（任一格不少于 16 字）\(\sigma = 0.20\)。每个观测点放出 8 条轨道，随机源固定为种子 42。轨道终点是粒子。粒子矩阵的均值再单位化，得到云中心 \(\mu\)。

没有对上列名的列仍然留下一朵云，但 \(\mu\) 为空。空云不能连箭头，也不能向切空间贡献向量。这一步把「没有观测」和「观测很散」分开。

### 从云到箭头

只在种类相同、并且两侧 \(\mu\) 都存在的列之间连箭头。球面长度是大圆距离

\[
L = \arccos(\mu_s \cdot \mu_d)
\]

夹角先截到 \([-1, 1]\)。\(L\) 同时当作这条箭头的分配代价。种类不同的列即使方向接近也不连，短文本不会去解释长文本。

\(L\) 自己还不决定搬运。它要和后面的近邻判定一起用。

### 从箭头到切空间基

粒子先不平均。在本云中心 \(\mu\) 处做黎曼对数映射，模长等于大圆距离 \(\theta\)，不是弦长 \(\sin\theta\)：

\[
\log_\mu(p) = \frac{\theta}{\sin\theta}(p - \cos\theta\cdot\mu), \quad \theta = \arccos(\mu\cdot p)
\]

源云的这些切向量沿大圆平行移动到目标中心 \(\mu_d\)。记源点 \(p\)、目标点 \(q\)、\(c = p\cdot q\)。若 \(c \le -1\)，两点接近对径，搬运没有唯一结果，这条切向量丢掉。否则

\[
v \mapsto P_q\left(v - \frac{v\cdot q}{1+c}(p+q)\right)
\]

全部搬过来的切向量叠成矩阵，做奇异值分解。均方根长度记为 \(r\)，阈值是 \(\max(10^{-6}, r\sigma)\)，\(\sigma\) 仍按目标列的短文本或长文本选取。大于阈值的右奇异向量留下来，张成 \(V_{\mathrm{in}}\)。小于等于阈值的方向丢掉。一个方向都留不下时，基是空的。

这一步的结果是目标切空间里的一张允许平面。它回答：源列的名字扰动，搬到目标之后，还占哪些方向。

### 能量决定分类还要不要看箭头

目标自己的对数向量分解到 \(V_{\mathrm{in}}\) 和它的正交补上：

\[
E_{\mathrm{in}} = \sum \|P_{\mathrm{in}} v\|^2, \quad
E_{\mathrm{out}} = \sum \|v - P_{\mathrm{in}} v\|^2, \quad
\rho = \frac{E_{\mathrm{out}}}{E_{\mathrm{in}}+E_{\mathrm{out}}}
\]

基为空时，能量全部算在外面。

若 \(E_{\mathrm{out}} > E_{\mathrm{in}}\)，或者两者相等且外面不为 0，这一列就是 `outspan`。规则名 `E_out_gt_E_in`。域内能量很小但仍然大于域外时，不另设绝对门槛。此时近箭头的个数不再改变类别。能量已经说明目标的扰动主要落在源列张成的平面之外，后面的球面长度只作为记录，不把这一列说成搬运或派生。

只有能量没有判成 `outspan` 时，才数近箭头。源云半径加目标云半径得到跨度。半径是对数向量长度的均方根。一条箭头要满足

\[
L \le r_s + r_d
\]

日期列另走虚拟箭头。日位差除以 `Z_DAY_UNIT`（365）。超过一年的不连。两侧都有列名云时，还要同时满足上面的半径和。能量只用来自列名粒子，不把日差混进 \(E_{\mathrm{in}}\)。

近箭头个数决定剩下的三类：

| 近箭头 | 类别 | 含义 |
| --- | --- | --- |
| 至少 2 | `derived` | 目标落在多条源列共同张成的方向里，不能记成某一列的原样搬运。 |
| 恰好 1 | `carry` | 只有一条源列足够近，按这条箭头的源列名和表名记账。 |
| 0 | `inspan_miss` | 能量在平面内，但没有一条箭头近到能指出来源。 |

多条近箭头按 \(L\) 从小到大排列。列名用 `|` 接在 `field` 里，表名同样接在 `source_sheet` 里。这是测地线内部的多源态射记号。写回映射时，多源派生会检验自然拼接同态，禁止静默截断为单源。

### 测地线结果怎样进入映射

映射的顺序是固定的。公式列先占位。数字通道和沿指针的原文比对其次。测地线只填还没被占住的文本列。

因此 `carry` 变成 `cell_role=data`，源和字段来自那一条近箭头。多源 `derived` 会尝试探索字符串拼接同态（如连接符 `""`、`" "`、`"-"`），若成立则合成公式 `cell_role=formula`（Excel 外链）或带算子闭包的 `cell_role=data`（Google）；若无法自动闭环则严格标记为 `cell_role=input` 并附带 `unresolved_derived_requires_manual_merge` 告警，绝不静默丢弃次要源或伪装成单源 data。`outspan` 与 `inspan_miss` 变成手工输入，置信度为 0。本地没有对应 BERT 权重时，整段测地线返回空列表，文本列不会被这段数学改写；若指针上的原文已经对上，那些列在此之前就已经定案。

## 样本工作流

`example_workflow.py` 是这个包的样本入口，不再单独承担「只读表」的职责。它读取 `docs/sample/执法堂业绩.xlsx` 的 `sheet1`、`sheet2` 作为源，读取 `docs/sample/sample_template.xlsx` 的 `Input_sheet` 作为已填模板。读入之后调用 `run_text_align` 和 `recover_mapping`（其中包含数字对齐与 `regex_deduce`），再把 `[sources]`、`[[input_section]]` 和 `[[fields]]` 打成 TOML，写到标准输出。

在仓库根目录执行：

```
python -m geodesic_align.example_workflow
```

标准输出是 TOML。标准错误最后一行是 `time_ms`，分别给出读表、数字与正则、测地线、拼 TOML 和总耗时，单位毫秒。

标签在第 1 行、值在第 2 行，所以样本里的 `value_from_label` 是 `down`，`input_area` 覆盖第 2 行。正则仍用 TOML 单引号字面量。
