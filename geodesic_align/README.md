# geodesic_align

本模块用于从已填充的模板表格中反向还原目标列与源数据表之间的映射规则。列的通道分流仅依据单元格字面内容自动判定，不依赖表头的业务语义：可编码为复数形式的数值列进入**数字通道**，其余自然语言文本列进入**球面测地线通道**。两条通道最终输出统一格式的映射规则，类型包括：搬运（carry）、并集（union）、派生计算（formula/derived）、正则提取（regex），无法自动识别的则降级为手工输入（input）。

数值列的原始值不输入 BERT 模型，也不参与切空间运算。文本通道不是在欧氏空间上另加的一组球面技巧，而是一般凯勒测地线里工业上还能算的那种坍缩，见下文「两次降维」。

## 复数通道（数字通道）

### 复数编码规则
每个单元格内容编码为一个复数：
\[z = x + yi\]
其中实部 \(x\) 为可比较的标量值；虚部 \(y\) 仅用于标记数据洁净度与异常拓扑，不参与四则运算。

| 虚部取值 | 含义说明 |
| --- | --- |
| \(y = 0\) | 干净实数。包含普通数值、合法日期对应的 Excel 序列号、纯时刻对应的日分数。 |
| \(y > 0\) | 越界日期（已向下钳位至合法日期）。\(y\) 记录被钳掉的天数，例如平年的 `1978-02-29`、`2026-02-30` 会被钳位到 2 月 28 日，分别记 \(y = 1\) 与 \(y = 2\)。 |
| \(y = -1\) | 哨兵值 \(0 + (-1)i\)。空格、`N/A`、`暂无`、`-` 及各类公式错误均归入此类。全程不使用 `NaN`，也不抛出异常。 |

哨兵值之间不判定为相等：只要任意一侧 \(y < 0\)，相等性判定 \(z_{eq}\) 结果即为假。两侧均为非哨兵值时，要求实部差值的绝对值小于 \(10^{-9}\) 且虚部完全相等。因此，合法日期与被钳位到同一天的日期不相等，不同空白单元格之间也不相等。

进入集合运算前，实部与虚部分别四舍五入至小数点后 8 位作为量化键，避免二进制浮点精度误差导致同一数值被拆分为两个集合元素。

日期的实部采用自 1899-12-30 起算的 Excel 序列号（例如 2026-10-08 对应整数 46303，二者对应同一个 \(z\) 值）；时刻折算为当日占比（例如正午对应 0.5），叠加到日期实部中。百分号数值会预先除以 100，自动剥离货币符号与千分位分隔符，自动识别欧式逗号小数格式，会计格式的括号负数如 `(1,234.50)` 统一规范为普通负数。以上所有清洗操作都在生成复数 \(z\) 之前完成。

结构化代码类内容不编码为复数 \(z\)（这类内容缺乏稳定的连续实部），搬运校验时直接对比首尾去空格后的原始文本。

### 复数结果的分流逻辑
哨兵值（\(y < 0\)）不进入主键集合。有效集合为空的列直接跳过，不参与覆盖度计算。

对于目标离散列集合 \(S_D\) 与源列集合 \(S_S\)，定义三个评估指标：
\[\mathrm{Coverage} = \frac{|S_D \cap S_S|}{|S_D|}, \quad \mathrm{Uniqueness} = \frac{|S_S|}{\text{源表非空行数}}, \quad \mathrm{Score} = \mathrm{Coverage} \times \mathrm{Uniqueness}\]

覆盖度为 1 且唯一率不低于 0.8 的列对，优先选为行指针（Row Pointer）；单列无法完全覆盖时，才尝试多列并集方案。目标单元格为空时，对应行指针记为 `None`，不会因局部空缺否定整列的匹配性。

锚定行指针后，非主键列仅在已填充的有效行上执行 \(z_{eq}\) 校验，按优先级依次判定：
1. **搬运（Carry）**：若有效样本逐格相等，直接判定为搬运（单源 `carry` 或跨表 `union_carry`），不再尝试代数合成。
2. **四则派生（Derived）**：若无法直接搬运，则搜索加减乘除二元算子的组合。公式成立要求所有有效行的虚部均为 0，且左右操作数都不是常数列（实部集合元素数 > 1），以此过滤加零、乘一、常数拼凑这类无意义的公式。
3. **正则抽取（Regex）**：仍未匹配的列，沿同一批行指针进入正则匹配流程。目标文本必须是源单元格的连续子串；如果是日期类字面非子串的情况，则对比捕获组解析后的 \(z\) 值。正则匹配优先尝试具名锚点、括号、分隔符等通用模式；如果无法闭环匹配，则调用本地 `gemma-4-e4b-it-coder` 生成候选正则表达式，再用 Python 对全量样本回测验证。正则对齐全程依赖行指针对齐，不默认两表行数相等。

## 文本测地线通道

### 两次降维

一般凯勒结构由势函数 \(K\) 决定，度规是二阶混合偏导 \(g=\partial\bar{\partial}K\)。在 768 维隐空间里直接求这个黑塞矩阵，测地线方程也没有闭式，编译期和运行期都承受不了。本通道把这个问题坍缩两次。后面的单位化、大圆、对数映射、平行移动和能量门控是坍缩之后剩下的运算，不是额外套上的启发式。

第一次降到常曲率单位超球面 \(S^{d-1}\)（\(d=768\)，实维数 767）。统计流形上，Čencov 定理给出的 Fisher–Rao 度规经过平方根嵌入之后就是球面圆度规，所以单位化是度规本身，不是预处理。复射影空间 \(\mathbb{CP}^{383}\) 的 Fubini–Study 度规则是奇数维球面圆度规除掉 \(U(1)\) 相位后的商。BERT 给出的是实向量，没有这个相位可除，实现就停在实球面上，不进入 \(\mathbb{CP}^{383}\)。球面上的测地线是大圆，长度有闭式
\[\theta=\arccos(\mu_s\cdot\mu_d)\]
内积先截断到 \([-1,1]\)。这一步把「数值求解凯勒测地线方程」换成一次内积和一次反余弦。

第二次不再比较曲率张量。黎曼对数 \(\log_\mu(p)\) 把球面上的点映到切空间，切向量模长等于弧长 \(\theta\)，不是弦长 \(\sin\theta\)。沿大圆的 Levi-Civita 平行移动把源切向量搬到目标切点 \(\mu_d\)。源列覆盖得到的方向张成允许平面 \(V_{\mathrm{in}}\)，目标扰动拆成平面内能量 \(E_{\mathrm{in}}\) 与正交补能量 \(E_{\mathrm{out}}\)。判定
\[E_{\mathrm{out}}>E_{\mathrm{in}}\]
在凯勒语言里是全纯破缺：扰动离开了源列能解释的方向。坍缩到实切空间之后，它就是正交破缺，该列降为手工输入 `input`。弯曲底流形上的「湖泊蓄水还是瀑布外流」因此变成 \(T_{\mu_d}S^{d-1}\) 里的一次线性投影。

\(S^{767}\) 的实维数是奇数。凯勒流形的实维数必须是偶数，所以生产路径上的底流形本身不是凯勒流形，也没有复结构 \(J\)。对径点（内积 \(\le -1\)）处平行移动不唯一，代码直接丢掉该切向量；这是球面割迹，不是还没算完的曲率项。

### 不要加回去的计算

李雅普诺夫吸引盆地不能当作另一套分类器加回来。粒子云漂移 \(-\lambda(x-x_0)\) 已经是球面函数 \(V(x)=1-x\cdot x_0\) 的梯度，投到切空间后再缩回球面。每个粒子的盆地就是它自己的观测点，只负责把云的半径留在局部，不判断两列是否同源。\(E_{\mathrm{out}}>E_{\mathrm{in}}\) 在切空间里已经是这个判定的二次型，子水平集就是 \(V_{\mathrm{in}}\)。再积分一条吸引子轨迹，只是把一次矩阵乘法换回一条轨道。

凯勒全纯闭合也不要恢复。\(\omega=i\partial\bar{\partial}K\) 的闭合在 Fubini–Study 上是恒等式，不是运行期要检验的量。要用它，就得先选定复结构并回到混合黑塞，也就是撤掉第一次降维。实向量没有相位，大圆上的平行移动闭式已经是球面的 Levi-Civita 联络，全纯标架不会改变 \(\theta\) 或 \(V_{\mathrm{in}}\)。`manifold_evolution.evaluate_closure` 检查的是线性子空间的能量比 \(\rho\)，而且生产路径不调用该模块，不要把它当成 \(d\omega=0\)。

40 步 Euler–Maruyama 是坍缩模型里唯一还在离散积分的部分。切空间中的线性奥恩斯坦–乌伦贝克过程有闭式方差，但每步都缩回球面之后，转移核是 767 维球面热核，勒让德级数并不比这 40 次矩阵乘法便宜。在回归确认 `carry` / `outspan` 不变之前，不要用切空间高斯闭式替换这 40 步。

对于自然语言文本列，将每一行内容拼接为「列名：值」的格式（空值与哨兵值不参与拼接）。整句仅执行一次 BERT 前向传播，提取每个 token 的隐向量。设置参数 `GAUSS_SIGMA` 为列名中心到各 token 的高斯衰减宽度，仅保留字符区间重叠比例达到 `OVERLAP_TAU`（默认 0.85）的 token 参与高斯加权平均，随后对结果做单位化处理。

这一步会将列名的语义表征投影到单位超球面 \(S^{d-1}\) 上。后续的距离计算、平行移动、能量分解都在该球面的切空间（Tangent Space）中进行，避免在欧氏空间中混淆方向与模长。完成谱分解后，奇异值低于噪声基底，或小于最大奇异值乘以 `SPECTRUM_OMEGA` 的方向会被直接截断丢弃（即 ω 谱截断策略，而非采用经验余弦阈值）。

### 从单点表征到粒子云
分类判断不依赖静态的单点表征，而是基于列名在各行样本上的局部分布特征。算法首先在观测均值的切空间中提取主成分基底 \(B\)，再沿主方向执行 Euler–Maruyama 随机微分方程积分；正交补方向仅注入 \(0.1 \cdot D^{-1/2}\) 的微弱背景噪声，避免 768 维各向同性噪声将能量弥散到补空间。

设切空间投影算子为 \(P_x\)，步长 \(\Delta t = 0.05\)，积分步数 40，阻尼系数 \(\lambda = 1\)，扩散过程如下：
\[\xi = z B + 0.1\, D^{-1/2}\eta, \quad x \leftarrow \mathrm{unit}\Big(x + P_x\big(-\lambda (x - x_0)\big)\Delta t + \sigma \sqrt{\Delta t}\, P_x(\xi)\Big)\]

短文本的扩散强度 \(\sigma = 0.08\)，长文本（任意单元格内容不少于 16 字）\(\sigma = 0.20\)。每个观测点释放 8 条扩散轨道（随机种子固定为 42），所有轨道终点构成粒子云，对粒子位置取均值后再次单位化，得到云中心 \(\mu\)。

未匹配到对应列名的列仍保留空云结构，但其 \(\mu\) 为空值；空云不参与测地线态射连接，也不向切空间提供基底。该机制严格区分了「无观测数据」和「观测结果高度发散」两种情况。

### 从粒子云到测地线态射
仅当两列文本类型相同、且两侧云中心 \(\mu\) 均存在时，才会在列之间连接测地线箭头（态射）。球面距离采用大圆测地线长度计算（内积先截断到 [-1, 1] 区间）：
\[L = \arccos(\mu_s \cdot \mu_d)\]

该距离 \(L\) 同时作为该态射的最优传输分配代价。不同类型的文本列即使语义方向接近也不建立连接（例如短文本列不会匹配长文本列）。\(L\) 值不单独决定是否为搬运关系，需要结合后续的切空间能量、近邻半径条件联合判定。

### 从态射到切空间基底
粒子不会预先做平均，而是在各自云中心 \(\mu\) 处执行黎曼对数映射（映射后的向量模长严格等于大圆弧长 \(\theta\)，而非弦长 \(\sin\theta\)）：
\[\log_\mu(p) = \frac{\theta}{\sin\theta}(p - \cos\theta\cdot\mu), \quad \theta = \arccos(\mu\cdot p)\]

之后将源列的切向量沿大圆测地线平行移动（Parallel Transport）到目标云中心 \(\mu_d\) 处。设源中心为 \(p\)、目标中心为 \(q\)，\(c = p\cdot q\)。若 \(c \le -1\)（两点接近对径点），平行移动不存在唯一解，直接丢弃该切向量；否则按照 Levi-Civita 联络进行搬运：
\[v \mapsto P_q\left(v - \frac{v\cdot q}{1+c}(p+q)\right)\]

将所有平行移动到目标点的切向量拼接成矩阵，执行奇异值分解（SVD）。设切向量长度的均方根为 \(r\)，截断阈值取 \(\max(10^{-6}, r\cdot\sigma)\)（\(\sigma\) 根据目标列是长/短文本选取）。保留大于阈值的右奇异向量，张成目标切空间内的**允许平面 \(V_{\mathrm{in}}\)**；如果没有符合条件的方向，则基底为空。

\(V_{\mathrm{in}}\) 定义了几何解释的边界：源列的列名扰动经过球面平行移动后，在目标切空间中能够覆盖的方向范围。

### 能量判定边界与态射分类
将目标列自身的对数切向量分别投影到允许平面 \(V_{\mathrm{in}}\) 和其正交补空间，计算两部分的能量：
\[E_{\mathrm{in}} = \sum \|P_{\mathrm{in}} v\|^2, \quad E_{\mathrm{out}} = \sum \|v - P_{\mathrm{in}} v\|^2, \quad \rho = \frac{E_{\mathrm{out}}}{E_{\mathrm{in}}+E_{\mathrm{out}}}\]

若基底为空，则全部能量计入正交补 \(E_{\mathrm{out}}\)。

- **正交能量越界（Outspan）**：若 \(E_{\mathrm{out}} > E_{\mathrm{in}}\)（或二者相等且 \(E_{\mathrm{out}} > 0\)），该列直接判定为 `outspan`，对应规则名为 `E_out_gt_E_in`。此时目标列的扰动主要落在源列张成的允许平面之外（凯勒全纯破缺在实切空间里剩下的正交破缺），后续仅保留球面距离作为记录，不再将该列归类为搬运或派生。当 \(E_{\mathrm{in}} > E_{\mathrm{out}}\) 时，不额外设置绝对能量阈值。
- **近邻态射计数**：仅当能量未判定为 outspan 时，统计近邻态射的数量。设源列、目标列的云半径 \(r_s, r_d\) 为各自对数切向量长度的均方根，有效近邻态射必须满足跨度约束：
  \[L \le r_s + r_d\]
  日期列单独走虚拟态射逻辑：日期差值除以 `Z_DAY_UNIT=365`，跨度超过一年则不建立连接；若两侧同时存在列名粒子云，则必须同时满足上述半径和约束，且日期差值不纳入切空间能量 \(E_{\mathrm{in}}\) 的计算。

近邻态射的数量最终决定三类态射归属：

| 近邻态射数 | 类别 | 几何与业务含义 |
| --- | --- | --- |
| \(\ge 2\) | `derived`（派生） | 目标列落在多条源列共同张成的切平面内，属于多源复合派生，不能标记为单列搬运。 |
| \(= 1\) | `carry`（搬运） | 仅有一条源列进入近邻半径跨度内，直接按该态射对应的源表、源列标记为字段搬运。 |
| \(= 0\) | `inspan_miss`（内空未命中） | 扰动能量在允许平面内，但没有任何源列中心进入近邻跨度，无法确定单一来源。 |

多条近邻态射按大圆距离 \(L\) 升序排列，源列名与源表名用 `|` 拼接后记入 `field` 与 `source_sheet` 字段（测地线通道内部的多源态射标记）。输出最终映射规则时，多源派生列会强制校验字符串拼接同态，禁止静默简化为单源搬运。

### 测地线结果收敛为配置映射
映射合成遵循严格的优先级占位规则：**原生公式列优先占位 → 数字通道与行指针对齐的原文比对次之 → 测地线通道仅填充剩余未判定的文本列**。

- `carry` 转化为 `cell_role="data"`，数据源与字段名取自唯一的近邻态射。
- 多源 `derived` 会自动探索字符串拼接同态（例如连接符 `""`、`" "`、`"-"`）：如果验证闭环，则合成为外链公式 `cell_role="formula"`（Excel 物理表）或带算子闭包的 `cell_role="data"`（Google 物理表）；如果无法自动闭环，则严格降级为 `cell_role="input"`，并附带 `unresolved_derived_requires_manual_merge` 告警，绝不会静默丢弃次要来源，也不会伪装成单源搬运。
- `outspan` 与 `inspan_miss` 统一转为手工输入 `cell_role="input"`，置信度记为 0。
- 当本地未挂载 BERT 权重时，测地线通道安全返回空列表，不修改任何文本列的判定；此前已通过行指针对比锁定的列不受影响。

## 示例工作流
`example_workflow.py` 是本包的端到端示例入口：读取 `docs/sample/执法堂业绩.xlsx` 中的 `sheet1`、`sheet2` 作为源数据表，读取 `docs/sample/sample_template.xlsx` 的 `Input_sheet` 作为已填充模板；依次调用 `run_text_align` 与 `recover_mapping`（内部包含数字对齐与正则推导），最终将 `[sources]`、`[[input_section]]` 与 `[[fields]]` 序列化为 TOML 格式输出到标准输出。

在仓库根目录执行以下命令即可运行：
```bash
python -m geodesic_align.example_workflow
```
