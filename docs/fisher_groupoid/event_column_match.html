用 MLM 把表列变成向量再对齐

实现见 fisher_groupoid/column_match.py。 只用本地 BERT，不读表头字符串、不读外部字段映射文件。 先把格子洗成统一字面，再各列做成两个向量（内容长什么样、对整行贡献了什么）， 日期列额外沿「年份跨度」方向挪一小步，最后用门禁决定谁配谁。

0. 术语从哪来、用线代怎么读

下文专有名词保持英文。本科线性代数里已经够用的运算只有：向量、内积 \(\langle u,v\rangle\)、长度 \(\|u\|\)、单位向量 \(u/\|u\|\)、 把 \(v\) 投到 \(u\) 上 \(\langle v,u\rangle u\)（\(u\) 已单位化）、再拿走这部分得到与 \(u\) 垂直的残差。 其余词是从别的课借来的绰号，下表给出出处和在本文中的具体意思。

术语 出处 用本科线代怎么理解（本文用法）
BERT 自然语言处理。Devlin 等 2018，Bidirectional Encoder Representations from Transformers。 一个固定的函数：输入一段文字，输出 \(\mathbb{R}^{768}\) 里的一个向量。本文当黑盒用，不训练。
MLM 同上论文的训练任务 Masked Language Model：遮住一个词，让模型猜回去。 只说明我们用的是 BERT 这类编码器，不是聊天用的 LLM。配对过程不调用任何对话模型。
LLM Large Language Model，生成式大语言模型。 本文不用。列出是为了和 MLM 区分。
token / pooled vector NLP 习惯。token 是切词后的小块；pooling 是把许多小块合成一个。 句子被切成若干 token，每个有一个 768 维向量。把这些向量做算术平均，得到代表整句的一个向量。
unit 线性代数：单位化。 \(\mathrm{unit}(u)=u/\|u\|\)。只保留方向，去掉长短。零向量不除。
cosine 线性代数：两向量夹角的余弦。 \(\cos(a,b)=\langle a,b\rangle/(\|a\|\|b\|)\)。1 表示同向，0 表示垂直，−1 表示反向。用来当「像不像」的分数。
event sentence 本文用语。一行业务记录当成一件事。 把该行非空格子的字面用顿号串起来，得到一句给 BERT 的输入。不含列名。
value cloud 本文用语。cloud 只表示「一堆点的平均」。不是云计算。 一列里每个非空格子各做一个单位向量，再平均、再单位化。表示「这列内容长什么样」。
leave-one-out (LOO) 统计学交叉验证：拿掉一项再看差别。不是新几何。 整行句向量减去拿掉该列后的句向量，得到一个差向量。表示「这一列给整件事多带来了什么」。按行先单位化再平均，避免长句子把差变得特别大。
canonicalization 软件工程 / 数据清洗：把同一事实写成同一种标准形。 把 1978/2/29、1978-03-01 00:00:00、19830101 都改写成 YYYY-MM-DD。非法日期（如 1978-02-29）仍当字符串，不用 Python datetime 去验证闰年。
common mode 电路与信号处理：许多导线共享的那一段电压，叫共模。 所有日期字符串都共享的方向，例如「这是用连字符连起来的数字」。若把这个方向从每个日期向量里减掉，连「哪一年」的差别也会被削掉，所以本文不用。
projection / orthogonal 线性代数：正交投影。 把 \(v\) 投到单位向量 \(u\) 上是 \(\langle v,u\rangle u\)。\(v\) 减去它，得到与 \(u\) 垂直的部分。SDE 里要对时间方向做这一步，否则时间方向几乎和日期字面平行，挪了等于没挪。
collinear 线性代数：共线，一个向量是另一个的标量倍。 两个单位向量 cosine 接近 1，就是几乎共线。所有 YYYY-MM-DD 在 BERT 里都几乎共线，所以单靠字面很难分开「上报日」和「生效日」。
SDE 随机过程课：Stochastic Differential Equation，形如 \(dX=f\,dt+\sigma\,dW\)。本科常只见到常微分方程 ODE。 本文并不真的抽样布朗运动。只借用「沿某个力的方向走一小步」这个图：给日期向量加上与年份均值、年份标准差成比例的一项。代码是一次加法再单位化，不是微分方程求解器。
Langevin 统计物理：有摩擦的布朗运动，粒子被力拉着走，同时被随机碰撞搅动。 绰号。本文只用了「拉力」那一项（drift），没有加随机碰撞。drift 由该列年份的平均值和标准差决定。
renormalization / 穿衣 统计物理与量子场论：裸参数经过环境修正变成有效参数。Wilson 重整化群。 绰号。裸向量 = 格子字面的平均；穿衣 = 再叠上年份跨度信息。不是换模型、也不重新训练 BERT。
Euler step 本科常微分方程数值方法：\(x\leftarrow x+h f(x)\)。 只走一步：新向量 = 单位化(旧向量 + 系数 × 时间方向)。步长信息已经折进系数 \(\gamma,\beta\)。
temporal axis / epoch 时间轴；epoch 在天文学和地质学里表示「以某年为原点的时刻」。 用 BERT(1978年) 减 BERT(2026年) 得到一个 768 维方向，当作「更早 vs 更晚」。年份先减 2000 再除以 30，变成大约 \([-1,1]\) 的数，避免年份绝对值太大。
mean / std 本科概率统计：平均与标准差。 一列里各个年份对应的 \(\tau_i\) 的平均值 \(\bar\tau\)、标准差 \(\sigma_\tau\)。两行都是 2026 则 \(\sigma_\tau=0\)；从 1978 跨到 2030 则 \(\sigma_\tau\) 较大。
unique-slot 指派问题 / 匹配：一个源列最多占一个模板列。 贪心：分数最高的先挑。模板列被占用后别人不能再要。分数不够高、或两个模板列分数太接近，就空着不配。
floor / type_floor / margin 算法门限。margin 在假设检验里表示「要高出多少才算分得清」。 floor=0.5：最高分低于 0.5 不配。type_floor=0.5：次高分也过 0.5 才可能构成竞争。margin=0.08：最高分必须比这些竞争者至少高 0.08，否则视为分不清，不配。
rivals 本文用语：竞争者。 同一源列上，除最优模板列以外、分数 \(\ge 0.5\) 且与最优分差 < 0.08 的那些列。
mutual nearest 匹配算法：A 的最近邻是 B，且 B 的最近邻是 A。 源列挑中模板列 \(d\) 之后，还要检查：在还没被占用的源列里，\(d\) 分数最高的必须是自己。
phi (\(\varphi\)) 数学里常用映射符号。 一张字典：源列名 \(\mapsto\) 模板列名。例如 ID → ID#。
char_equiv 本文验收函数，不参与打分。 去掉 #、_、空格后看两个列名是否相同。只用来事后核对，例如 ID 与 ID# 算相同，issues 与 Recent Issue 算不同。

1. 样本表

源表 docs/sample/执法堂业绩.xlsx。 sheet1 列：ID, name, gender, dob。 sheet2 列：ID, Report_date, issues。 模板 Input_sheet 列：ID#, Name, Recent Issue, Report Date, Discipline, Effective_Date, Sign。

对齐目标按列语义：sheet2 的 Report_date 应对到模板 Report Date；issues 对 Recent Issue；ID 对 ID#。 模板没有性别列。Effective_Date 在模板里是单独一列，不应被 sheet2 占走。

2. 为什么分两步

Excel 把日期对象印成 1978-03-01 00:00:00，模板里另一列却是 1978/02/29。 BERT 会觉得所有「带 00:00:00 的日期」彼此极像，于是 Report_date 对 Effective_Date 的内容相似度假高到约 0.97，方向反了。

第一步只做减法：把日期字面统一成 YYYY-MM-DD；不要从向量里减掉「日期长什么样」那个共有方向 （减完 0.967 > 0.947 会变成 0.598 < 0.632）；门禁改为「只有分差小于 0.08 的高分才算真分不清」， 不再「两个日期都超过 0.5 就全部拒绝」。

洗净后方向已经对了（Report Date 0.834，Effective_Date 0.831），但只高 0.003，过不了 0.08。 第二步才给日期向量加上年份跨度，让「从 1978 跨到 2030」和「两行都是 2026」分开。

3. 输出对象 SheetColumnMatch

match_source_to_template(src_sheet=...) 一次建成。

  • table：每对（源列，模板列）的分数。
  • phi：最终映射。
  • verify：事后列名核对，不进入打分。
  • unmatched_src / unmatched_dst：没配上的列。

4. 把格子写成标准日期

Excel 的日期对象用 %Y-%m-%d 打印；已经是字符串的，用正则改写。 接受 YYYY-MM-DD、YYYY/M/D、后面可带时刻、YYYYMMDD。 年 1900–2100、月 1–12、日 1–31，不做闰年检查，所以 1978/02/29 仍写成 1978-02-29。

5. 从格子到向量

5.1 一行合成一句

第 \(r\) 行、列 \(\ell\) 的字面记为 \(x_{r\ell}\)。空值和 NULL 丢掉。用中文顿号连接。不写列名。

\[ s_r = \mathrm{join}(\{x_{r\ell'}:\ x_{r\ell'}\neq\emptyset\}),\qquad s_r^{-\ell} = \mathrm{join}(\{x_{r\ell'}:\ \ell'\neq\ell,\ x_{r\ell'}\neq\emptyset\}). \]

5.2 句向量

含汉字则用 bert-base-chinese，每个句子一个 768 维向量：该句所有内容 token 的算术平均。

\[ v(s)=\frac{1}{|T|}\sum_{t\in T} h_t,\qquad \mathrm{unit}(u)=\frac{u}{\|u\|_2}\quad(\|u\|_2 \lt 10^{-12}\ \text{则不除}). \]

5.3 一列两个向量

内容向量：该列每个非空格子各做一个单位向量，再平均。

\[ u_\ell^{\mathrm{val}} =\mathrm{unit}\!\left( \frac{1}{|R_\ell|}\sum_{r\in R_\ell}\mathrm{unit}\big(v(x_{r\ell})\big) \right). \]

贡献向量：整句减去拿掉该列后的句子，差向量按行单位化再平均。长短句的差不会因为句子更长就自动更大。

\[ \Delta_{r\ell}=\mathrm{unit}\big(v(s_r)-v(s_r^{-\ell})\big),\qquad u_\ell^{\mathrm{loo}} =\mathrm{unit}\!\left( \frac{1}{|R_\ell|}\sum_{r\in R_\ell}\Delta_{r\ell} \right). \]

贡献向量描述的是「这句话里拿掉一块之后方向怎么变」，不要再按日期字面方向去投影。 模板同一行里往往同时有两个日期，拿掉一个，另一个还在，所以单靠贡献向量几乎分不开 Report Date 和 Effective_Date。

6. 为什么不减「日期长什么样」

所有标准日期在 BERT 里几乎共线。若先求出日期字面的平均方向 \(e_{\mathrm{date}}\)，再对每个列向量做 \(u\leftarrow \mathrm{unit}(u-\langle u,e_{\mathrm{date}}\rangle e_{\mathrm{date}})\)， 减掉的不只是「连字符格式」，连哪一年的差别也被削薄，分数顺序会反掉。 这段投影已经从特征函数里删掉。

7. 日期列沿年份方向走一步

格子仍是字符串；另外从年份算出两个普通统计量。 Effective_Date 两行都是 2026，年份没有离散程度；Report Date 与 Report_date 从 1970 年代跨到 2020 年代，离散程度大。

\[ \tau_i=\frac{\mathrm{Year}_i-2000}{30},\qquad \bar\tau=\mathrm{mean}_i\,\tau_i,\qquad \sigma_\tau=\mathrm{std}_i\,\tau_i. \]

时间方向先用「1978年」减「2026年」得到 \(e\)，再减去它在内容向量上的投影，得到与内容垂直的 \(e_\perp\)。 若不垂直，\(e\) 几乎顺着日期字面，加上去再单位化，向量几乎不动。

\[ e=\mathrm{unit}\big(v(\text{1978年})-v(\text{2026年})\big),\qquad e_\perp=\mathrm{unit}\big(e-\langle e,u^{\mathrm{val}}\rangle u^{\mathrm{val}}\big). \]

只改内容向量，不改贡献向量：

\[ \tilde u^{\mathrm{val}} =\mathrm{unit}\big(u^{\mathrm{val}}+(\beta\sigma_\tau-\gamma\bar\tau)\,e_\perp\big), \quad \gamma=0.25,\;\beta=0.45. \]

\(\beta\sigma_\tau\) 让「年份散得开」的列沿 \(e_\perp\) 多走一些；钉在同一天的列 \(\sigma_\tau=0\)，只按平均值微移。 sheet1 的 dob（1938 / 1983 / 2026）同样散得开，因此也会靠近 Report Date。这是同一条加法的结果。

8. 一对列怎么打分

\[ \cos(a,b)=\mathrm{clip}\!\left(\frac{\langle a,b\rangle}{\|a\|_2\|b\|_2},-1,1\right) \quad(\text{有一个是零向量则 }0). \]

普通列：内容相似度与贡献相似度各一半。两列都是日期：内容 0.7，贡献 0.3。

9. 谁配谁

代码默认含义
floor0.50最高分低于此不配
type_floor0.50次高分过此才可能算竞争者
margin0.08最高分须至少高出竞争者这么多

源列 \(\ell\) 的最高模板列记为 \(d^\star\)，最高分 \(S^\star\)。出现下面任一情况就不配：

  • \(S^\star < 0.5\)
  • 另有模板列分数 \(\ge 0.5\)，且与 \(S^\star\) 的差小于 0.08
  • 第二名与第一名的差小于 0.08
  • 在尚未占用的源列里，\(d^\star\) 最认的不是 \(\ell\)

例：Name 0.65 与 Sign 0.63，差 0.02，视为分不清，name 不配。 合成表里若某列对 Effective_Date 0.80、对 Report Date 0.56，差 0.24，可以保留。
